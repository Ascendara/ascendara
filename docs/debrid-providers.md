# Debrid providers

Download controls, source eligibility and queues use the generic provider registry. TorBox is the first adapter; another provider supplies its credentials setting, capabilities, operations and metadata serializer without adding branches to callers.

Debrid starts disabled. Enable it in Settings → Downloads to reveal the account editor and reorderable service list. Drag rows or use the arrows to save priority. Routing skips disabled accounts and accounts without API keys. TorBox is the default first service when no explicit order is saved. Cloud torrent support allows torrent-only sources without enabling local qBittorrent.

Hosted links use the first compatible configured service and honor its seamless-download preference. A provider API failure does not resubmit to another account. Existing TorBox metadata remains compatible.
