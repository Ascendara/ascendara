# Security Policy

## Supported versions

Security fixes are made for the latest release of Ascendara. Please update to the latest
release before reporting, and check whether the issue still happens there.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue, pull request or
discussion for a security problem.

You can report through any of these:

- GitHub private vulnerability reporting: open the
  [Security tab](https://github.com/Ascendara/ascendara/security) and choose
  "Report a vulnerability".
- A private direct message to a staff member on the
  [Ascendara Discord](https://ascendara.app/discord).
- <!-- maintainer: add a security contact email here -->

Include what you found, the affected version and OS, steps to reproduce, and the possible
impact. Remove any real API keys, tokens or personal information from your report.

## What to expect

We will acknowledge your report as soon as we can, keep you updated while we look into it,
and let you know when a fix is released. Please give us reasonable time to fix the issue
before sharing details publicly.
